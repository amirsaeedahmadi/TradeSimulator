# TradeSimulator

A simulation framework for experimenting with **stock trading strategies**, portfolio management, and market dynamics.  
This project provides a sandbox environment to test trading logic, evaluate performance under different conditions, and gain insights into algorithmic trading workflows.

---

## Features

- **Trade Simulation** – Execute buy/sell orders based on custom strategies.  
- **Portfolio Tracking** – Monitor balance, profit/loss, and asset allocation.  
- **Strategy Testing** – Plug in different trading strategies for evaluation.  
- **Market Replay** – Simulate trades against historical or synthetic data.  
- **Performance Metrics** – Collect statistics such as ROI, drawdowns, and volatility.  

---

## Repository Structure

- `src/` – Core simulator source code.  
- `strategies/` – Example trading strategies implemented in code.  
- `data/` – Sample datasets for running simulations.  
- `tests/` – Unit tests for verifying correctness.
